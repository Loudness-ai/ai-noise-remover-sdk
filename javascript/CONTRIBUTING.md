# Contributing

Use Node 22 or24 and a supported FFmpeg/FFprobe installation. Run `npm ci --ignore-scripts`, `npm run build`, `npm test`, `npm run test:types`, `npm run check:schemas` and `npm run lint`. Tests use real local decoding/encoding/inference and isolated temporary directories. Keep failure reports reproducible with a rights-cleared fixture, platform/runtime/codec versions, command/options and stable error code.

Do not replace checksummed assets without a reviewed model-adapter contract, provenance and delay/tail evidence. Preserve bounded memory, independent state, source protection, atomic commit, queued deadlines and confirmed process cleanup. No hosted API or telemetry may become a requirement for local processing. Avoid private production imports, credentials, arbitrary upload paths or raw native logs in public HTTP responses.

Quality/speed claims need matched input/settings and measured evidence. Tests must cover actual output and failure ownership, not only mocked invocations. Native Windows and physical mobile checks are tracked separately from configured CI. Keep compatibility aliases/types/schemas deliberate and documented.
